## 📋 Описание проекта

Современная интерактивная обучающая система, разработанная для студентов стоматологических факультетов, ординаторов и практикующих ортодонтов. Система предоставляет глубокое понимание биомеханических принципов ортодонтического лечения через теоретические материалы, интерактивные калькуляторы и симуляторы.

## ✨ Основные возможности

### 🎓 Теоретическая база
- Фундаментальные понятия: центр сопротивления, система сил, типы перемещений
- Биомеханика ортодонтических дуг и материалов
- Методология проф. Попова С.А.

### 🧮 Биомеханические калькуляторы
- **Расчет центра сопротивления** - определение положения ЦС для одно- и многокорневых зубов
- **Расчет M/F соотношения** - вычисление момента для различных типов перемещений
- **Калькулятор силы дуги** - расчет силы на основе материала, размера и деформации дуги
- **Анализ опоры** - оценка соотношения опорных и подвижных зубов

### 🔬 Интерактивный симулятор
- Визуализация различных типов ортодонтических перемещений
- Настройка параметров: тип зуба, сила, M/F соотношение
- Прогнозирование результатов лечения
- Клинические рекомендации на основе выбранных параметров

### 🏥 Клинические случаи
- Детальный разбор реальных клинических ситуаций
- Биомеханический анализ с расчетами
- План лечения и используемая механика
- Ключевые моменты по методологии проф. Попова

## 🔬 Биомеханические расчеты

Система использует научно обоснованные формулы и методики:

### Центр сопротивления
```
Однокорневые зубы: h_цс = L / 3
Многокорневые зубы: h_цс = L / 2
```

### Момент пары сил
```
M = F × d
M/F = 0 (наклонно-вращательное)
M/F = 7-8:1 (корпусное, однокорневые)
M/F = 10-12:1 (корпусное, многокорневые)
M/F = 10-12:1 (корневое перемещение)
```

### Сила ортодонтической дуги
```
F = (3 × E × I × δ) / L³

где:
E - модуль упругости
I - момент инерции
δ - деформация
L - активная длина
```
